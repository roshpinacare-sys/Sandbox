## כשלים-מדודים-שנתוקנו-ב-T-47 (אפס-אמון-עצמי)

1. **vaultlib.sh — גילוי-קרדנשל עיוור ל-remote-URLs**: המכונה-החיה החזיקה-קרדנשל-
   תקף בתוך-`.git/config` והכספת-סירבה-להיפתח ("keyless-honest"). תוקן: מקור-
   גילוי-חדש (ריפו-ממלכה-כלשהו → חילוץ-טוקן, לעולם-לא-מודפס).
2. **vault.sh — `VAULT_PASSPHRASE` ללא-export**: openssl `-pass env:` קורא
   סביבת-תהליך-הבן; השמה-רגילה-נעלמת-ממנו → "WRONG PASSPHRASE" שקרי. תוקן:
   `export`. **זו-הייתה-הסיבה-שהפתיחה-האוטונומית-מעולם-לא-עבדה-מה-wrap-registry.**
3. **auto-unseal.sh — פריסת-מעטפות ללא-תיקיית-אב + אי-סנכרון-פריסה** בין-
   פריסת-FleetHQ-לפריסת-ריפו-עצמאי. תוקן: `mkdir -p` + שיקוף-כספת-מוצפנת
   ל-$VAULT_DIR. **בדיקה-קרה מאומתת: מחיקת-כל-מצב-מקומי → auto-unseal → RC=0.**
