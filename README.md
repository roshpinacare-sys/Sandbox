# Sandbox — תיקיית-האם הריבונית של הרשת

> השרת-המפעיל. במקום-הסנדבוקסים-האפמרליים שמתים-כמה-פעמים-ביום — **התשתית-הקבועה** שממנה-מורצת-כל-האוטונומיה-הריבונית. הגיט-הוא-הקיום; הרצה-היא-פונקציה-של-הגיט, לא-של-מכונה.

## העקרון המכונן

1. **הגיט = מקור-האמת.** כל-מה-שתלוי-בסנדבוקס חי-כאן: קוד · קונפיגורציה · קבלות · פרוטוקולים. מחיקת-סנדבוקס = אירוע-שגרתי-בלתי-רלוונטי.
2. **הרצה-חסרת-מדינה.** העורק-האוטונומי רץ ב-GitHub Actions (v2-רצף: cron+push+dispatch+שרשרת-עצמית — לא-תלוי-במתזמן): pull → עבודה → push → הפקת-הטביעה-הבאה. ה-runner מת-בסוף-כל-ריצה — **וזה-מכוון**. הרציפות-חיה-בריפו, לא-בזיכרון.
3. **הסיסמה-היא-השער.** קונסולת-המפעיל (`console/`) מוצפנת-כולה; היא-נפתחת-רק-בסיסמה-הראשית. **אף-חומר-סיסמה לא-שמור בריפו** — לא-קלט, לא-האש, לא-רמז. רק-צופן.
4. **אפס-סודות-בגיט.** טוקנים = GitHub Secrets בלבד. מפתחות = מחוץ-לרשת-הזו לגמרי. סריקת-דליפות-חובה לפני-כל-דחיפה.
5. **swarm-משמעת.** חמישה-סוכנים על-עץ-משותף: טריטוריות-קבצים נפרדות · fetch+rebase לפני-push · אסור-force-push · `worklog.md` append-only · כל-סוכן מכריז-את-שטחו.

## מבנה העץ

```
console/                  ← קונסולת-המפעיל (אתר מוצפן, נפתח-בסיסמה בלבד)
  index.html              ← הקליפה-הציבורית (שער-הסיסמה, RTL)
  sealed-payload.bin      ← התוכן-המוצפן (AES-256-GCM)
  params.json             ← salt+iv+פרמטרים (מידע-פומבי, לא-סודי)
engine/                   ← סקריפטים-ניידים (stdlib בלבד — רצים ב-Actions וגם-מקומית)
tools/seal.mjs            ← חותם-הקונסולה (רץ-מקומית-בלבד; הסיסמה-לעולם-לא-נוגעת-בדיסק/לוג/גיט)
workflows → .github/      ← עורק-האוטונומיה (cron) + פריסת-אתר (Pages)
docs/RUNBOOK.md           ← חוזה-ההקמה-הקנוני של-כל-סנדבוקס-חדש
network/                  ← לוח-הרשת הציבורי (T-42): דופק-חי · פעימות · מבט-FleetHQ · ריצות-Actions — אפס-סודות
SECURITY.md               ← מודל-האיום וחוקי-הבטיחות
worklog.md                ← יומן-ה-swarm (append-only)
```

## איך-זה-מריץ-את-הרשת

- **קצב-חיים אוטונומי (v2-רצף · T-42)**: `.github/workflows/sovereign.yml` — כל-15-דק' GitHub-עצמו מריץ-את-עורק-הריבונות: אימות-המשכיות, קבלות-טביעה, push-חזרה. **השרשרת-העצמית** (repository_dispatch ← chain-next) מבטיחה-רצף-גם-כשמתזמן-ה-cron-מדלג (וזה-נמדד: 11-משבצות-שקטות-ב-2026-10-09). אפס-תלות בשרת-חי.
- **פריסת-אתר**: `.github/workflows/pages.yml` מפרסם את `console/` ל-Pages — השער-למפעיל, מוצפן-קליינט-סייד.
- **סנדבוקס-חדש**: clone → PAT → `docs/RUNBOOK.md` → חזרה-לחיים. התיקייה-היא-המקור; הסנדבוקס-הוא-רק-ידיים.

## מדרגות-הסמכות (מוחזקות)

- **אוטונומי-מלא**: קבלות · אימות-המשכיות · טביעות-מצב · תחזוקת-העץ.
- **שמור-למפעיל-בלבד**: venue · מפתחות-ושחזורם · שידור-עסקאות · פרסום-תוכן · סיסמה-ראשית.

## הקוקפיט-המפעיל (agent-2 · T-37-cockpit)

**https://roshpinacare-sys.github.io/Sandbox/cockpit/** — השכבה-שמימשה-את-מה-שagent-1 שמר-למפעיל: מפתחות · שידור · פרסום.

| רכיב | תפקיד |
|---|---|
| `docs/index.html + app.js + style.css` | קוקפיט-חי: שער-מעטפות · לוח-15-חשבונות-חי (שתי-שרשרות) · vote/claim/comment/follow/reblog חתומים-בדפדפן · ביקורת-נאמנות חקוקה |
| `docs/vault.enc.json` | כספת-הצי (v2, רישום-מעטפות): סוד-אב-אקראי חותם-את-הפליילוד · כל-סיסמה-מקובלת = מעטפה משלה (PBKDF2 600k + AES-256-GCM) · **הדבקת-headcorner.txt-המלא פותחת-גם-את-console/ (קנון-משותף)** |
| `docs/vendor/gate-crypto.js` | קריפטו-אפס-תלות — מוצמד-verbatim מ-SovereignConsole (איחוד, לא-הסתעפות) |
| `boot/bootstrap.sh` | מכונה-חדשה + קרדנשל → fleet-vault-unseal + כספת-צי-ROT4 (סיכות-sha256 כפולות) → ריבונות-מלאה |
| `boot/verify.sh` | מטריצת-נאמנות מול-שרשרת-חיה אחרי-כל-אתחול |

**ביקורת-הנאמנות (חקוקה-בכספת, מוכחת-שרשרת 2026-10-09):** headcorner 4/4 חי · hcsoldier4/5/6 4/4 חי · 10 מפעילים: owner חי/שאר מיושן (חסום-לחתימה בקוד) · headconer לא-בשרשרת. פסק-צומת-חי על-חתימת-הדפדפן: `verify_authority = TRUE`.

## השער-המאוחד של המפעיל (agent-2 · T-38-operator)

**https://roshpinacare-sys.github.io/Sandbox/operator/** — סיסמה-אחת פותחת-בבלוק-אחד: כספת-הצי (מעטפות-קוקפיט) · הקונסולה (קנון-62) · מצב-העורק-מקבלות-חיות · בריאות-השרשרת מול-api.steemit.com. הקריפטו = פורט-verbatim מ-`docs/app.js` + `tools/seal.mjs` — אפס-הסתעפות.

| רכיב | תפקיד |
|---|---|
| `operator/index.html + gate.js + style.css` | שער-מאוחד + לוח-מפעיל (6-פאנלים) · CSP 'none' · אפס-אחסון · נעילה-אוטומטית 15 דק' |
| `operator/server/worker.mjs` | **שער-שרתי אמיתי** (מוכן-לפריסה): PBKDF2·650k · constant-time · rate-limit 5/15 דק'/IP · session-HttpOnly·HMAC·TTL-8h · פרוקסי-מאומת לכל-הפתחים |
| `operator/server/deploy.sh` | פריסה-בפקודה-אחת מקומית: קנון→PBKDF2→wrangler-secret→deploy (אפס-סודות-בגיט; hash-חי-רק-ב-Cloudflare) |

**מצב-אמת:** טוקן-ה-Cloudflare-בכספת מת (נמדד-מול-API בהקמה) → השער-השרתי מוכן-ולא-חי; ההצעה: טוקן-רענן → ROT5 → `deploy.sh` → חי.

## מדינת-הרשת-החיה + פעולות-המפעיל (agent-3 · T-43)

- **`status/`** — דף-מצב-ציבורי (https://roshpinacare-sys.github.io/Sandbox/status/): נורות-חיות · שרשרת-מרקל-מצטבר · מתג-ריבונות · יומן-טיקים. **ההוכחה-שלא-תלויה-בטענות** — כל-מה-שמוצג נמדד בענן ונקרא מהגיט.
- **`state/network-state.json`** — מדינת-הרשת: keeper · selftest · מתג · custody-echo · chain. חוק-אחד: אפס-מספרים-שלא-נמדדו. החוזה המלא: `state/README.md`.
- **`.github/workflows/sovereign-state.yml`** — עורק-המדינה: cron-מוסט (3,18,33,48) + **פעולות-מפעיל-לפי-בקשה**: health · selftest · snapshot · arm · disarm (GITHUB_TOKEN-בלבד; arm-מחייב-נימוק).
- הפרדת-סמכויות נשמרת: הקונסולה-והקוקפיט = שערי-הסודות (agent-1/2); המדינה-והפעולות = שכבת-ההנהגה (agent-3).

**https://roshpinacare-sys.github.io/Sandbox/agents/** — כניסת-הצי לבית-הגיט: לא רק המפעיל-האנושי. כל-סוכן-רשום (agent-1..agent-5) נכנס-בזהות-מאומתת, קורא-את-תיבת-הפקודות-המוצפנת, רואה-מדינה-חיה-וקבלות, ומדווח-מהענן-באתגר-מענה.

| רכיב | תפקיד |
