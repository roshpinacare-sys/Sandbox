## חוקי-האמת (אנטי-מחמאה)

1. **overall** = הדרגה-הגבוהה-שנצרתה: OK < NOTICE < DEGRADED < FAIL.
2. כל-כלל = **סף-מספרי מ-config.json** — לא דעת-סוכן, לא טון.
3. כל-שורת-דוח = ראיה (URL ריצה / טימסטמפ RPC / נתיב-קובץ).
4. בלתי-ניתן-למדידה = **UNMEASURED/UNREACHABLE** — מדווח-כנה, לעולם-לא-מנוחש.
5. הדוח-אף-פעם-לא "מרכך": לולאה-מתה = FAIL עד-שתימדד-אחרת.

## פלטים (כולם-בטריטוריה)

- `REPORT.md` — דוח-מלא (נדרס-בכל-ריצה) + דלתא-מול-הריצה-הקודמת (השתפר/התדרדר).
- `TASKS.md` — מאגר-משימות-חי append-only: כלל-נצרת → OPEN (עם-ראיה); כלל-הבריא → CLOSED.
  זו-לולאת-הלמידה: ההיסטוריה-נבחנת-אוטומטית ומניבה-רשימת-עבודה-מדויקת-במקום-טענות.
- `state/verifier/history.jsonl` — פנקס-מרקל (tail-512; דפוס-federation).
- `state/verifier/verdict-latest.json` — קבלת-הראש (למנועים/פאנלים).

## הרצה

- CI: workflow `verifier (truth & quality)` — משבצות :07/:37 + שרשרת-עצמית (דפוס-T-42).
- מקומי: `node engine/verifier.mjs --local` · אימות-פנקס: `node engine/verifier.mjs --verify-ledger`.
- כללים: `config.json` בטריטוריה-זו — שינוי-סף = שינוי-מדיניות-מוצהר, לא שינוי-קוד.

- ריפואים-פרטיים: נקראים עם טוקן-קריאה (דפוס-federation); בלי-טוקן = `UNVERIFIED-PRIVATE`.
