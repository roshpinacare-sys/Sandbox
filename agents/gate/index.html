    קבלות-השער (12-אחרונות) טוען

      פעולות-מאומתות מהענן (אתגר-מענה)

      הטוקן-אף-פעם-לא-עובר-על-החוט: ה-runner כותב-אתגר → אתה-מחשב proof=sha256(טוקן:אתגר) → ה-runner מאמת-ושורף. הקבלה-נכתבת-ונדחפת-ע"י-ה-runner-עצמו.

      1. 1 · אתגר
        gh workflow run agent-access.yml -f agent_id=ID -f action=challenge
      2. 2 · הוכחה
        proof = sha256(טוקן + ":" + אתגר-המקובץ-מהקומיט החדש ב-agents/challenges/)
      3. 3 · אימות
        gh workflow run agent-access.yml -f agent_id=ID -f action=verify -f proof=HEX64
      4. 3b · דיווח
        gh workflow run agent-access.yml -f agent_id=ID -f action=report -f proof=HEX64 -f text="דיווח-כנה"
