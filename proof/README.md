# proof/ — הוכחת-מתים עומדת (R11 · saos/key-proof/1)

**מה זה מוכיח:** שכל חומר-מפתח שדלף להיסטוריית-git הציבורית של
`roshpina · anchor-baseline · saos-jummper · Sdk · Adsmarket` — לא מאשר
**דבר** על אף אחד מ-14 חשבונות-הצי בשרשרת החיה. לא סיבוב-ריפואים אצל
ה-owner אלא הוכחה מבוססת-שרשרת שמתרעננת מדי שבוע (workflow `key-proof`,
יום-ד' 04:23 UTC). זה שער-**R11** מתמוסס: "חומר-מפתחות חשוף בהיסטוריה"
→ הוכחה עומדת שהחומר מת.

**איך מריצים:**

```bash
node proof/key-proof.mjs --selftest          # 26/26 · אפס רשת · חובה לפני הכל
KP_TOKEN=… node proof/key-proof.mjs          # ריצה חיה מלאה (או GITHUB_TOKEN)
```

קריאה-בלבד לשרשרת (`api.steemit.com` ועמיתיו) — אין שידורים, אין כתיבות,
אף כספת לא נגעה. תוצרים: `proof/out/key-proof-<YYYY-MM-DD>.json` +
`KEY-PROOF-LATEST.json` (זהים).

**חוק-הצנזורה (ברזל):** בארטיפקט ייכתב **רק** sha256-16hex של חומר-המועמד,
מפתח-ציבורי נגזר, ומטא-דאטה של מקום (ריפו/בלוב/נתיב/קומיט). אף חומר-פרטי,
אף סיסמה, אף תוכן-קובץ. ה-auditor רץ על הארטיפקט כולו לפני כתיבה — הפרה =
כשל-קשה, **כלום לא נכתב**. הערכים עצמם חיים בזיכרון בלבד ונמחקים עם התהליך.

**קריפטו:** פורט אפס-תלות מ-`Domain/gate-crypto.js` (אומת מול steem-js) —
secp256k1 BigInt ג'קוביאני + base58check + ripemd160 טהור; checksum של
STM = ripemd160(pub33)[:4]. עגון: KATs של EC/rmd160/WIF + מפתח-ציבורי-חי
מהשרשרת ב-selftest.

ומעולם לא נפתח (נכון-ל-design — הצנזורה אוסרת) — קיים-בתיעוד כ-hash בלבד;
וה-9 חיילים דורשים-מפתחות-owner לרוטציית-רשויות — ראו
