# RUNBOOK — חוזה-ההקמה-הקנוני של-כל-סנדבוקס-חדש

> התיקייה-הזו-היא-השרת. כל-סנדבוקס-הוא-רק-זוג-ידיים-אפמרלי. זה-החוזה-שמקים-אותן.

## הקמת-סנדבוקס-חדש (3-צעדים)

```bash
# 1) קבלת-התשתית (התיקייה-היא-המקור)
git clone https://github.com/roshpinacare-sys/Sandbox.git && cd Sandbox

# 2) קבלת-סמכות — המפעיל מזריק-PAT (שורה-אחת, gitignored):
#    ללא-PAT: הסוכן עובד-קריאה-בלבד ומדווח-חסר-סמכות. אין-המצאת-טוקנים.

# 3) עורק-החיים — הרצת-טביעה-ראשונה:
node engine/sovereign-tick.mjs --local
```

הסנדבוקס-חי. הוא-אף-פעם-לא-מחזיק-מצב-קנון — הוא-מושך-מכאן, עובד, דוחף-חזרה.

## הכללים

1. **מצב-קנון רק-בגיט.** כל-קבלה/היסטוריה/שושלת — קבצים-בריפו, נדחפים-פר-טביעה.
2. **טביעה = pull → עבודה → סריקת-דליפות → commit → rebase-על-origin → push.** אסור-force-push. קונפליקט = rebase-כנה, המצב-החי-מנצח, נרשם-בworklog.
3. **טריטוריות:** כל-סוכן מכריז-שטח-בworklog ונוגע-רק-בו. קבצים-משותפים (worklog/README) = append/תיקון-מדויק-בלבד.
4. **חסם-לפני-כל-push:** `node engine/leak-scan.mjs --staged` — אפס-התאמות או-אין-push.
5. **עדכון-הקונסולה:** עריכת-תבנית-מקומית `tools/payload-template.json` (**gitignored — הפליינטקסט-לא-נדחף-מעולם**) → `cp <קובץ-סיסמה> .passfile && node tools/seal.mjs && shred -u .passfile` (רץ-מקומית-בלבד; הסיסמה-רק-בזיכרון) → commit-הצופן-החדש → `node engine/leak-scan.mjs --staged --passfile <קובץ-סיסמה>` לפני-push.

## העורק-האוטונומי (GitHub Actions)

- `sovereign.yml`: cron `*/15 * * * *` + dispatch-ידני. ה-runner: checkout → `engine/sovereign-tick.mjs` → commit+push-קבלות. הסמכות: `GITHUB_TOKEN` (contents:write) — אפס-PAT-ב-CI.
- זו-התשובה-הארכיטקטונית-למחיקות: **GitHub-עצמו הוא-המנוע**; סנדבוקס-חי-הוא-תוספת-נוחות, לא-תנאי-קיום.

## סדר-היחלצות

| תקלה | טיפול |
|---|---|
| push-נדחה (מישהו-דחף-חוד) | `git pull --rebase` → טפל-קונפליקט-כנה → push |
| סריקת-דליפות-מאירה | **עצור.** אתר, תקן-מקור, שקול-סיבוב-סוד-לפי-SECURITY.md |
| Actions-אדום | קרא-את-הלוג-בריפו → תקן-את-הסקריפט → commit — זה-כל-התיקון |
| סנדבוקס-נמחק | חזור-לצעד-1. הכול-כאן. |
