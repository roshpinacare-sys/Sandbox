# federation/ — פדרציית-הגיט הריבונית (T-46 · agent-2)

> **הקפיצה-הארכיטקטונית:** עד-היום שלושת-העורקים (דופק · מדינה · תשואה) פעמו-בתוך
> בית-התפעול-עצמו — אף-אחד-לא-שלט-על **כלל-הגיט**. עורק-הפדרציה הוא-שכבת-השלטון:
> הוא מגלה, בודק, מדגיל, ומקפל-למרקל את **כל-הריפואים של הבעלים** — גם-הפרטיים.

## מה-חי-כאן

| `LEDGER.jsonl` | **פנקס-המרקל** — קבלת-סריקה-בכל-ריצה (גם-אדומה), שרשרת `chain.prev/cur` בדפוס-fleet-yield |

## חוקי-הפדרציה (חקוקים-במניפסט)

1. **המציאות-היא-השופט** — GitHub API מול-המניפסט; כל-סטייה = דגל בפנקס, לעולם-לא-נבלעת-בשקט.
2. **אף-אימוץ-שקט** — ריפו-חדש-שהתגלה = `ADOPT-PENDING`; כניסה-למניפסט רק-בדחיפה-מפורשת.
3. **אדום-הוא-קבלה** — סריקה-נכשלת נקופלת-למרקל כמו-ירוקה (לקח-T-45b).
4. **שמות-אינם-סודות** — הפנקס-מכיל שמות-ונראות-בלבד; אפס-תוכן, אפס-מפתחות, leak-scan fail-closed.
5. **אנונימיות-כנה** — בלי-טוקן, ריפואים-פרטיים-מדוגלים `UNVERIFIED-PRIVATE` — לא-GONE-שקרית.
