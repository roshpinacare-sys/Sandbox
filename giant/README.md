## מה-זה giant

התיקיה-הקנונית של **הפלטפורמה המאוחדת** — כל-מה-שיש-בגיט הופך כאן מדפים-מפוזרים
למערכת-תוכנה-ווב אחת שימושית, בתקן-הענקים. אין-כפילויות: ערוץ-אחד, משרד-אחד,
מערכת-אחת. הכל-בגיט; הסוכנים-מתים, giant-נשאר.

## חוקי-הבית (מחייבים-כל-סוכן)

1. **חוק-הערוץ-האחד**: ערוץ-תקשורת **אחד** בלבד בעלים↔ריבונות. אסור-להקים-ערוץ
   נפרד. ערוצים-קיימים מהגל-הראשון (5-ערוצים) — מתאגדים-פנימה-לפי
   `SPEC-CHANNEL.md` (מקור-נודד: ops/sovereign/OWNER-CHANNEL/inbox.jsonl
   הוא **קו-הבליעה הקנוני בגיט**; ה-decider-כבר-קורא-אותו-בכל-פעימה).
2. **חוק-אין-כפילויות**: שני-משרדים? שני-ערוצים? שני-דפים-לאותו-תפקיד? **מצמצמים**.
   ניתוח-לפני-איחוד: לוקחים-את-הלימון, עושים-לימונדה — המיטב-מכל-סוכן מתגלגל-
   למערכת-אחת. חולשה-של-אחד-הופכת-עוצמה-של-הכל.
3. **חוק-הפרונט-והבק**: פרונט-גלוי-מקצועי-לא-שבור (מה-שמשווק-לקרובים);
   בק-חסוי-ומכני (מנועים, מפתחות, פנימים). ניהול-הבעלים מאחורי-שער-מפתח-
   acct-00 (הסוד-ב-upload/acct-00.txt-במכונה-בלבד; **אף-פעם-לא-בגיט,
   לא-בלוג, לא-בפלט**).
4. **חוק-המטבע-שלנו**: מרכז-הכובד = המטבע/הכלכלה/הדקס/הארנק שלנו. **לא-מדגישים**
   Steem/Hive/Blurt — מדגישים מטבעות-גדולים ורשתות-מוכרות כנקודות-התחברות.
   נזילות-נכנסת-לדקס-שלנו בכל-דרך-אפשרית.
5. **חוק-הוכחת-הווליום-קודם**: ריבונות-פרטית-עושה-הכל-לעצמה עד-הוכחה-ודאית:
   ווליום-גבוה-מאוד-על-הדקס (M-9) והתפתחות-מוצרים-אוטונומית: מסחר-נגזרות,
   הלוואות, מינוף — כמו-ענקים-ורק-יותר-טוב כי-הם-מיושנים-ואנחנו-חדשניים.
6. **חוק-האוטונומיה-ללא-סוף**: המערכת-אף-פעם-לא-גמורה. הצי תמיד בודק, מתקן,
   בונה, משפר, מייעל, פורץ-דרך, מאבטח, מפעיל, משחק, מנסה, מייצר. כל-משמרת
   משאירה-את-המערכת-טובה-יותר-ובגיט.
